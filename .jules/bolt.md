## 2026-11-03 - Optimize validate-skills.sh bash script
**Learning:** Shell scripts that spawn multiple subprocesses (`awk`, `head`, `wc`, `tr`) per file inside loops can be significant performance bottlenecks, especially in I/O bound checks or environments with high process creation overhead. Consolidating logic into a single robust stream processing pass (like a single `awk` script combined with process substitution and `read`) dramatically reduces execution time. Using `IFS` and a single octal escape character (like `\034`) ensures correct field parsing without running into variable truncation or process synchronization issues.
**Action:** When working on cross-platform Bash scripts that process large numbers of files, optimize loops by reducing the number of external subprocesses spawned. Collapse text processing commands (grep, sed, awk, head, tail, wc) into singular awk or native bash implementations whenever possible. Use safe delimiter strings and process substitution instead of evaluating command strings to securely and efficiently pass multi-line string outputs to bash variables.
