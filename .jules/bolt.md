## $(date +%Y-%m-%d) - Optimize validate-skills.sh parsing loop
**Learning:** In bash scripts processing many files in a loop, spawning multiple subprocesses (like `head`, `awk`, `tr`, `wc`, `basename`, etc.) inside the loop adds significant overhead and can slow down the script considerably. The `validate-skills.sh` script was spawning multiple such processes per skill file, leading to slow execution times (e.g. ~38s for 100 iterations).
**Action:** Consolidate text processing and parsing logic into a single pass using `awk` and avoid subprocesses for string manipulation (e.g. using string substitution for `basename`) to dramatically speed up execution (e.g. ~10s for 100 iterations). Use `read -r` with `IFS=$'\034'` to safely assign multiple output variables from the single awk pass.
